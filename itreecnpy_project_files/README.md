# Original i-Tree Canopy project and service reports

- `i-tree canopy project file.itrcnpy`: original Lake Eymir i-Tree Canopy project.
- `canyon.pdf` and `Ada.pdf`: original reports for the two primary climate-ranked configurations.
- `WallaWalla.pdf`, `Lincoln.pdf` and `Adams.pdf`: **not yet deposited**. These original reports informed the extended five-proxy comparison and are intended for later binary upload.

The publicly available `../point-target-2026/results/itree_top5_service_comparison.csv` contains the extracted biophysical totals and Canyon-relative percentage differences. Its arithmetic and the missing-value treatment of Lincoln can be checked with `../point-target-2026/scripts/verify_top5_services.py`.

After the missing PDFs have been added, `../point-target-2026/scripts/extract_top5_services.py` can verify the original report values with `pdftotext`. The report PDFs are outputs of the i-Tree application; they are not regenerated by the Python climate ranking script.
